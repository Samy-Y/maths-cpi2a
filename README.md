# Notes de cours de maths - CPI2A (Class2030)

*UM6P EMINES*

Ce dépôt contient les notes de cours de mathématiques pour la classe CPI2A (Class2030). Une interface pour la visualisation des fichiers PDF rendus est disponible via le site web [maths2.txt.ma](https://maths2.txt.ma) ou alternativement via [ce lien miroir](https://samy-y.github.io/maths-cpi2a).

Comme pour les leçons de la CPI-1A, les fichiers sont classés par grade de qualité. *Note: si les notes de cours sont toutes de bonne qualité 🙏, ces indices seront supprimés.*

Les styles/boîtes utilisées sont dans `coursmodern.sty` si vous voulez ~~les plagier~~ vous en inspirer :).

## Nomenclatures

À peu près comme pour la CPI-1A, sauf qu'ici c'est documenté.

| Élément | Description | Exemple |
|---------|-------------|---------|
| Fichier source/PDF | Nom `<date de création YYMMDD> CH<numéro du chapitre>.<pdf/tex>` | `260907 CH01.pdf` |
| Contenu du fichier PDF | Dernière date de mise à jour ; Lien principal vers le site ; Lien miroir si le lien principal ne marche pas | Voir contenu |
